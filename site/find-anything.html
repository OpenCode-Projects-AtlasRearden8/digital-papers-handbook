Once you've got a folder system, the real superpower is that you basically never need to browse folders. Search does it all — but only if you know a handful of moves.

The only search you need to memorize

  • Windows / Linux: Ctrl+F
  • Mac: ⌘ + F

That searches inside the file you have open. The other one, where you search across all your files, is this:

  • Windows: Windows key, then just start typing
  • Mac: ⌘ + Space (Spotlight), then just start typing
  • Most synced drives (OneDrive, Google Drive, Dropbox on the web): search box at the top

Between those two searches, you can reach any named file, and any phrase inside any file, in seconds. Everything else on this page is polish.

Ctrl+F moves worth knowing

When you're inside a PDF, webpage, or document:

You want... Type...
A tax form from a specific year the year, e.g. 2024
Someone's name in a long PDF the name, e.g. Asdale
All mentions, not just the first Enter again and again (or ⌘+G on Mac) to keep jumping
Slightly different spellings of a word type part of the word only: insur finds insurance, insured, insurer
A phrase, exactly the phrase in quotes: "due upon receipt"
The total on a statement $ followed by digits, like $1,2 (commas matter in many PDFs)
Where the page numbers are search for Page 12
Everything in a folder about survey use the folder-level search and type survey

Why some PDF searches come up empty

A scanned PDF is a photo. Search finds text, and a photo has none — unless the scan had its "text recognition" (OCR) step applied. Most phone scanning tools do this automatically (see Scanning). If yours doesn't:

  • Re-scan with the built-in Document/Scan mode — text usually gets recognized in the process.
  • Or run the file through a free OCR tool later. One time, permanent benefit.

Test it: open any scanned PDF and Ctrl+F for a word you know is in it. If you find it, OCR worked and that file is now permanently searchable. That's the whole benefit of this handbook, right there.

The search-first filing habit

Combine Folders and Naming with search and a rule emerges:

You don't file so you can browse. You file so that searching works.

A file named 2025-11-Electric-Bill-Nov-Paid.pdf in 05-Money is findable ten ways: by typing 2025-11 elect, electric bill, bill nov, browsing 05-Money, or Ctrl+F inside the file for the dollar amount. Overfiling (deep nested folders, five kinds of metadata) adds minutes and saves nothing.

Speed tricks, if you like this stuff

  • In Windows Explorer or Mac Finder, click into a folder and type the first letters of the file's name — the file gets selected. 2 0 2 5 e l e is faster than any scroll.
  • Ctrl+F also works in spreadsheets and word docs — and it's the same muscle memory everywhere, which is the point.
  • Pin your Papers/ folder to your file browser's sidebar so reaching it is one click.

That's genuinely all of it. When there are too many files for even search to be instant (a few thousand), that's when the optional AI-assisted filing chapter earns its keep.
